# Admin guide (for the site owner)

Sign in at **/admin** with your admin email. Forgot your password? Use "Forgot password?" on the sign-in page.

## The golden rule: Edit → Preview → Publish
- Every change saves automatically as a **draft** ("Draft saved" in the top bar).
- **Preview** opens the real site showing your draft; it updates live while you keep editing.
- **Publish** makes the draft live for everyone and saves a version. Nothing is live until you publish.
- Made a mistake? **Publishing → Version history → Restore**, then Publish. Or **Discard draft** in the
  Publish dialog to throw away unpublished edits.

## Common tasks
| I want to… | Go to |
|---|---|
| Edit a lesson like PowerPoint | Courses → pick level/module → lesson → **Slides** tab. Click text to edit; use the ribbon to insert; drag thumbnails to reorder; ⌘Z undo |
| Add a lesson / module / course | Courses → "+ Course", module page "Add module", module page "Add lesson" |
| Attach a PDF or slide deck | In the slide editor → last slide "Downloads" → Upload PDF or PPT; or insert a **PDF / PPT** slide to show it inside the page |
| Change a lesson's picture | Slide editor → title slide → pick an illustration (or "Auto") |
| Write a blog article | Blog → New article → edit slides → Mark as published → Publish |
| Show an offer when people land | Offers & banners → New offer → choose Banner or Pop-up → switch on → Publish |
| Change logo, favicon, colours, fonts | Theme (try a Quick theme, then fine-tune) → Publish |
| Change homepage text, FAQ, menu, footer | Website |
| Set the 1:1 booking link | 1:1 Connect → paste your Calendly / Cal.com / Topmate link → Publish |
| Approve reviews | Reviews → Pending → Approve (instant, no publish needed) → Feature to show on the homepage |
| Add an announcement | Content library → Announcements & notifications |
| Rename or recolour a level | Levels |
| Upload images / PDFs | Media (images are resized automatically) |
| Give someone admin access | They need a login (Supabase → Authentication → Add user); then Users → open them → Make admin |
| Back up everything | Publishing → Download draft as JSON |

## Good habits
- Preview on your phone before publishing big changes (theme, navigation, levels).
- Keep offers short and switch them off when they end (or set an end date).
- Only publish real numbers in Statistics and real, permitted quotes in Testimonials.
- Learners' progress lives in their own browser — encourage them to use **Profile → Download my progress**
  if they switch devices.
